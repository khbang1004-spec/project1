# Math Care Studio (SEL 기반 수학 수업 도구)

학생/교사 화면이 분리된 정적 웹앱 프로토타입입니다.

## 포함 기능

1. 수학 감정 날씨 체크인
- 학생이 현재 수학 감정을 날씨 아이콘으로 선택해 제출
- 교사는 학급 감정 분포를 실시간으로 확인

2. 가치 있는 오답 갤러리
- 교사가 제시한 익명 오답에 대해 학생이 "왜 나올 수 있는 오답인지" 투표
- 오답 공감 랭킹으로 사고 과정 중심 피드백 가능

3. 마이크로 해빗 트래커
- 점수 대신 수업 중 작은 행동 습관 달성 여부 체크
- 누적 해빗을 바탕으로 격려 포인트 확인

## 화면 구성

- `index.html`: 역할 선택(학생/교사 로그인)
- `student.html`: 학생 제출 화면 + 학생 개인 누적 리포트
- `teacher-login.html`: 교사 PIN 인증 화면
- `teacher.html`: 교사 대시보드 + 학생별 누적 관찰 테이블

## 실행 방법

1. `index.html`을 열어 학생/교사 화면으로 이동
2. 교사 대시보드는 `teacher-login.html`에서 PIN 인증 후 접근
3. 학생 화면에서 이름(별명) 저장 후 체크인 제출
4. 교사 화면에서 학급 전체 누적/학생별 누적 현황 확인

## 교사 접근 제어

- 기본 교사 PIN: `2468`
- PIN 인증 후에만 `teacher.html` 접근 가능
- 교사 화면의 "로그아웃" 버튼으로 세션 종료

## 학생 입장 제어 (명단 기반)

- 교사 화면에서 학생 명단(반코드, 학번, 이름) 사전 등록
- 학생은 `student.html`에서 반코드+학번+이름을 입력해 1단계 인증
- 인증 성공 후에만 2단계 활동(감정 체크인/오답 갤러리/해빗 트래커)과 개인 리포트가 열림
- 등록 정보와 불일치하면 입장 차단
- 인증 5회 연속 실패 시 10분 동안 재시도 잠금
- 인증된 학생만 체크인/오답/해빗 제출 가능

## 2번 기능(오답 갤러리) 확장

- 교사 화면에서 오답 사례를 직접 추가 가능
- "현재 학생 화면에 표시할 문제"를 선택해 활동 문제를 큐레이션
- 학생은 활성화된 오답 사례의 이유 버튼 중 하나를 선택해 공감 투표

## 참고

- 현재 버전은 브라우저 `localStorage`를 사용합니다.
- 같은 브라우저에서는 새로고침 후에도 누적 데이터가 유지됩니다.
- 교사 화면의 "전체 데이터 초기화" 버튼으로 누적 데이터를 비울 수 있습니다.
