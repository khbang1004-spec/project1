# Math Care Studio (SEL 기반 수학 수업 도구)

학생/교사 화면이 분리된 정적 웹앱 프로토타입입니다.

## 포함 기능

1. 수학 감정 날씨 체크인
- 학생이 현재 수학 감정을 날씨 아이콘으로 선택해 제출
- 교사는 학급 감정 분포를 실시간으로 확인

2. 가치 있는 오답 갤러리
- 교사가 제시한 익명 오답에 대해 학생이 "왜 나올 수 있는 오답인지" 투표
- 오답 공감 랭킹으로 사고 과정 중심 피드백 가능

3. 마이크로 해빗 트래커
- 점수 대신 수업 중 작은 행동 습관 달성 여부 체크
- 누적 해빗을 바탕으로 격려 포인트 확인

## 화면 구성

- `index.html`: 역할 선택(학생/교사 로그인)
- `student.html`: 학생 제출 화면 + 학생 개인 누적 리포트
- `teacher-login.html`: Google Apps Script 인증 화면
- `teacher.html`: 교사 대시보드 + 학생별 누적 관찰 테이블

## 실행 방법

1. `index.html`을 열어 학생/교사 화면으로 이동
2. 교사는 `teacher-login.html`에서 본인 Google Apps Script 웹앱 URL을 먼저 저장
3. 같은 화면에서 Google 인증 후 교사 대시보드 접근
4. 교사 화면의 학생용 링크를 복사해 학생에게 공유
5. 학생은 공유받은 링크로 접속해 반코드+학번+이름으로 입장 후 활동 제출

## 교사별 독립 교실 구조

- 각 교사는 본인 Google 계정으로 배포한 Apps Script 웹앱 URL을 사용
- 교사 데이터는 각자 연결한 시트/스크립트에만 저장되어 서로 섞이지 않음
- 학생은 교사가 공유한 학생용 링크의 `backend` 파라미터를 통해 같은 교실 저장소에 연결됨
- 교사 화면은 Google Apps Script 웹앱 인증 후에만 `teacher.html` 접근 가능
- 교사 화면의 "로그아웃" 버튼으로 세션 종료

## 학생 입장 제어 (명단 기반)

- 교사 화면에서 학생 명단(반코드, 학번, 이름) 사전 등록
- 학생은 교사가 공유한 `student.html?backend=...` 링크에서 반코드+학번+이름을 입력해 1단계 인증
- 인증 성공 후에만 2단계 활동(감정 체크인/오답 갤러리/해빗 트래커)과 개인 리포트가 열림
- 등록 정보와 불일치하면 입장 차단
- 인증 5회 연속 실패 시 10분 동안 재시도 잠금
- 인증된 학생만 체크인/오답/해빗 제출 가능

## 2번 기능(오답 갤러리) 확장

- 교사 화면에서 오답 사례를 직접 추가 가능
- "현재 학생 화면에 표시할 문제"를 선택해 활동 문제를 큐레이션
- 학생은 활성화된 오답 사례의 이유 버튼 중 하나를 선택해 공감 투표

## 참고

- 현재 버전은 교사별 Apps Script 원격 저장과 브라우저 캐시를 함께 사용합니다.
- 원격 저장이 실패하면 현재 브라우저 캐시에 임시 보관됩니다.
- 교사 화면의 "전체 데이터 초기화" 버튼으로 누적 데이터를 비울 수 있습니다.
